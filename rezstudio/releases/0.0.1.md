## RezStudio 0.0.1

The first pre-release of RezStudio, an RStudio-style IDE for R built on Zed. It's an early
build for trying out and giving feedback, for Apple Silicon Macs.

### Requirements

- A Mac with Apple Silicon.
- R 4.x, from CRAN's installer, rig or Homebrew. RezStudio finds it and starts it with the
  Ark kernel, which is bundled.
- Optional: [Quarto](https://quarto.org) to render `.qmd` files, and the `rmarkdown` package
  to render `.Rmd` files. `readr`, `readxl` and `haven` for Import Dataset.

### Installing

1. Open `RezStudio-0.0.1-aarch64.dmg` and drag RezStudio to Applications.
2. This build isn't notarized by Apple, so macOS blocks it the first time it's opened. Open it
   once, then go to System Settings → Privacy & Security and click **Open Anyway** next to
   the message about RezStudio.

There's no automatic updating yet: new versions are downloaded from the Releases page.

### What's in it

- **Console:** R through Ark, with rich output, interrupt and restart, and completion in the
  editor and console. Cmd+Enter runs the current line or selection.
- **Environment:** the global environment and attached packages, grouped into Data, Values and
  Functions and sortable. A data viewer that pages through large data frames. Memory use, saving and
  loading the workspace, Import Dataset for text, Excel, SPSS, SAS and Stata files, and
  function source from a click.
- **Plots:** plot history, redrawn to fit the pane, a zoom window, and copying and saving as
  PNG, SVG or PDF.
- **Packages:** installed and attached packages, updates, and instant search across CRAN,
  Bioconductor and R-universe.
- **R Markdown and Quarto:** chunks run inline with their output under them, an outline, and
  a Render button (Cmd+Shift+K) that shows the result in the Viewer.
- **Help and Viewer:** R's help in the app's theme, htmlwidgets, and Shiny apps.
- **Layout:** RStudio's arrangement, with Console, Terminal and Render below the editor and two
  stacked panes on the right that can be minimized and maximized. Tabs can be dragged between
  panes.
- **Dark mode for plots and pages:** a moon button in the Plots and Viewer panes darkens plots
  and light pages to suit a dark theme. Copied and saved plots keep R's colors.

### Known limitations

- Not notarized, as above, and Apple Silicon only.
- Python, the Typst preview and the debugger are planned but not in this release.
- The app icon is a placeholder.
- Settings are in `~/.config/rezstudio`, separate from Zed's. RezStudio is based on Zed
  1.27.0.
